# Open Decisions

Ordered by what blocks the most downstream work.

## 1. Path A ball ceiling — blocks kit packing

Teams build to whatever gauge they hold. Path A currently carries a 12mm ball, and Yoga can upgrade a struggling path mid-game. But if those four teams (2, 4, 6, 8) build 12mm catchers and apertures, a 20mm or 25mm ball physically will not pass and the lever cannot fire.

**Decide the ceiling, then put a gauge of that size in those four kits.** Make it a ball on a dowel handle, not a loose ball — a loose one gets rolled through the run "just to see", and if the gauge is also the upgrade ball, teams will simply start using it early.

## 2. Confirm 32mm passes a 25mm ball — blocks the whole materials set

32mm at 10kg gives ID ≈ 28mm, so a 25mm ball has 1.5mm clearance per side.

**Test:** roll a 25mm ball through a **32mm long-radius bend** and through a **freshly scissor-cut pipe end**, both under gravity at a shallow tilt.

- The bend, because a rigid ball cuts across a curve and presses into the outer wall. It needs a bend radius of at least ~50mm.
- The cut end, because a PVC scissor cutter pinches the bore inward by 1–2mm as it cuts.

If either hangs, the closed pathway moves to 40mm and every quantity shifts with it.

Note this makes **short 90° elbows impassable for the 25mm ball but fine for the 12mm ball** — worth knowing, since it becomes a real trade between paths.

## 3. Team 5 challenge wording

"Make an open air jump **within** 0.75 feet" — is that a minimum gap or a maximum? Currently written as a minimum, matching Team 4's, so it reads as an easier version of the same challenge.

## 4. Bucket diameter

Team 10 gets 2 and the depot holds 3, so the target width is fixed by what you buy. A narrow cup makes the dead drop the hardest module in the room; a wide bucket makes it nearly automatic.
