## Krishna: technique yes, strategy no

You designed the game. You know the trap items, who holds what, and which path needs braking.

**Can say:** how to cut square, how to deburr, how to brace a flexing frame, which tool to use.

**Must not say:** which fittings suit a ball path · which team holds what they need · that one path needs slowing and the other speeding up · anything starting with "have you tried…"

When tempted, ask a question instead of giving an answer.
